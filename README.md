# college-lost-and-found-system
A simple college project to help students report and find lost items on campus.
1. Launch the application by running 
python main.py in your terminal.
2. From the displayed main menu, select Option 1 to add a lost item (e.g., enter item name "ID Card", location
"Library", date, and contact number).
3. Log a found item using the appropriate system routine (Option 2 setup).
4. Test the search feature by choosing Option 3 or Option 4 and entering the target item name.
5. Use Option 5 and Option 6 to display all currently recorded lost and found item collections.
6. Test the termination sequence by selecting Option 7 to exit cleanly.
